## 📖 About

This is the source code for my personal portfolio website — a single-page, animated site built to showcase my work as a **Cloud & DevOps Engineer**. It's built with plain HTML/CSS/JavaScript plus Three.js for the 3D visuals, so it ships fast and runs anywhere without a build step.

## ✨ Features

- 🌍 **3D interactive globe** (Three.js WebGL) with animated network nodes, used in the Global Traffic / Architecture section
- ⌨️ **Typewriter hero text** cycling through role titles
- 🪐 **Orbiting-ring photo animation** around the profile image, with a glow effect on hover in the About section
- 📊 **Animated skill bars** across AWS, DevOps/Containers, and Linux/Git/Programming skill groups
- 🗂️ **Project showcase grid** with hover overlays linking out to GitHub repos
- 🕒 **Timeline-style education section**
- 📱 **Fully responsive** with a mobile nav menu
- 📄 **Downloadable resume** (PDF) linked directly from the hero section

## 🧱 Tech Stack

| Layer | Technology |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 (custom, no framework) |
| Interactivity | Vanilla JavaScript |
| 3D Graphics | [Three.js](https://threejs.org/) (r128) |
| Icons | Font Awesome 6 |
| Hosting | Vercel |

No build tooling, package manager, or bundler is required — it's static HTML/CSS/JS served directly.

## 🚀 Running Locally

No dependencies to install — just open the file or serve it statically:

```bash
git clone https://github.com/NiteshVishwakarma219/portfolio-frontend.git
cd portfolio-frontend
```

Then either open `index.html` directly in your browser, or serve it locally:

```bash
python3 -m http.server 8000
# visit http://localhost:8000
```
